# Marketing Campaign & Product Performance Analysis

## Overview

This project evaluates marketing campaign effectiveness and product category performance using customer-level data from Maven Marketing.

## Dataset

Maven Marketing Campaign Dataset

## Tools Used

- R
- dplyr
- ggplot2

## Key Findings

- The latest campaign achieved a 14.9% acceptance rate.
- Wine products generated approximately £680,816 in sales.
- Meat products generated approximately £373,968 in sales.

## Business Recommendations

- Investigate and replicate successful campaign characteristics.
- Prioritise high-performing product categories in future promotions.
- Explore cross-selling opportunities for lower-performing categories.
