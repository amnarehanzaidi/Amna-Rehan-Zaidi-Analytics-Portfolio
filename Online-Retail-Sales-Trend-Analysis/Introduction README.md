# Online Retail Sales Trend Analysis

## Overview

This project analyses transaction-level retail data to identify monthly, daily and weekly sales trends.

## Dataset

UCI Online Retail Dataset

## Tools Used

- Python
- Pandas
- Matplotlib

## Key Findings

- November 2011 generated the highest monthly revenue (£1.16M)
- Thursday generated the highest weekly revenue (£1.98M)
- Revenue increased significantly during the final months of the year

## Business Recommendations

- Increase inventory before peak periods
- Prioritise staffing during high-demand days
- Use seasonal patterns to support forecasting
